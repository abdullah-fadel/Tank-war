# Content Guide

How to extend Tank Assault's content without touching gameplay code.

## Add a new tank

1. `Assets/_Project/ScriptableObjects/Tanks/` → right-click → **Create → TankAssault →
   Tank Data**. Fill in `TankId` (unique, e.g. `tank_21`), stats, `DefaultPrimaryWeapon`/
   `DefaultMissileWeapon` (drag existing `WeaponData` assets), `Rarity`, unlock cost.
2. Duplicate `Assets/_Project/Prefabs/Player/PlayerTank.prefab`, swap the `Hull`/
   `TurretBody`/`CannonMesh` primitive meshes (or real art) and assign the new `TankData`
   to the `TankController`/`TankHealth` components' `Tank Data` field.
3. Add the `TankData` asset to the `ShopUI`/`InventoryUI` `allTanks`/`AvailableTanks`
   inspector arrays so it shows up for purchase/selection.

## Add a new weapon

1. **Create → TankAssault → Weapon Data**, pick a `WeaponType` and `DamageDeliveryMode`
   (`Projectile` needs a `ProjectilePrefab`; `Hitscan`/`Continuous` don't).
2. Add a `WeaponBase` subclass only if the delivery pattern is genuinely new — the seven
   existing subclasses in `Scripts/Weapons/` already cover Projectile/Hitscan/Continuous;
   most new weapons can reuse `CannonWeapon`/`PlasmaWeapon` etc. with different data.
3. Fill in 5 `WeaponUpgradeLevel` entries (damage/fire-rate/reload multipliers + cost).

## Add a new enemy type

1. **Create → TankAssault → Enemy Data**, pick an `EnemyType`/`EnemyMovementKind`, tune
   `BehaviourParamA/B/C` (meaning is defined per-AI-script — see the doc comment at the
   top of each file in `Scripts/Enemies/EnemyTypes/`).
2. If the attack pattern is genuinely novel, add a new `EnemyBase` subclass composing the
   reusable states in `Scripts/Enemies/AIStates/` (`IdleState`, `PatrolState`, `ChaseState`,
   `AttackState`, `FleeState`) — most patterns are a 20-30 line class, see `RocketTankAI.cs`
   for a mid-complexity example (salvo coroutine + stand-off distance).
3. Build a prefab: primitive/art body + `EnemyHealth` + your AI script + a `MuzzlePoint`
   child transform if it shoots. Assign the `EnemyData` asset to the AI script's
   (protected, so visible in the Inspector) `Enemy Data` field.
4. Reference the prefab from `EnemySpawner`/`EnemySpawnManager` spawn groups or the
   endless-mode pool.

## Add a new world/level

1. **Create → TankAssault → World Config**, set `Theme`, `RequiredWorldIndex` (which
   world must be complete first, or `-1` for always-unlocked), `AmbientMusic`.
2. Add `LevelInfo` entries: `Mode` (Story/Endless/Survival/Boss), enemy wave ids, star
   score thresholds, and which environment features are present (`HasBridges`,
   `HasMovingElevators`, `HasExplosiveBarrels`, `HasBreakableWalls`, `HasHiddenPaths` —
   these are just flags for your level designer/blockout, not auto-generated geometry).
3. Build the level scene: ground/terrain geometry (real level design work), place
   `EnemySpawner`s wired to an `EnemySpawnManager.SpawnGroup`, `Checkpoint`s,
   `ExplosiveBarrel`/`BreakableWall`/`MovingElevator`/`HiddenPathTrigger` instances, and a
   `LevelEndZone` at the finish line. Drop in a `LevelManager` with the `WorldConfig` +
   level index assigned.
4. Add the `WorldConfig` asset to `LevelSelectUI`'s `worlds` array.

## Add a mission or achievement

**Create → TankAssault → Mission Data** / **Achievement Data**, pick a `MissionType`
(`KillEnemies`, `KillSpecificEnemyType` + `TargetFilterId` = an `EnemyId`, `CompleteLevels`,
`EarnCoins`, `UseWeapon` + `TargetFilterId` = a `WeaponId`, etc.), set the target amount and
rewards. Add the asset to `MissionManager`/`AchievementManager`'s inspector array — progress
tracking is automatic via the event bus, no code changes needed.

## Replacing placeholder art

Every primitive mesh generated by `PrefabBuilder` lives under a named child transform
(`Hull`, `TurretBody`, `CannonMesh`, `Body`, ...) with a `MeshFilter`/`MeshRenderer`. To
swap in real art: delete the primitive child, parent your rigged mesh under the same
pivot transform (`TurretPivot`, `CannonPivot`, `MuzzlePoint`, ...) so existing aim/fire
logic keeps working unchanged, and wire an `Animator` + Controller for
`TankAnimationController`'s `Speed`/`Fire`/`Destroyed` parameters.
